PROJECT TITLE:
EnterpriseGPT — Secure Enterprise Retrieval Augmented Generation (RAG) AI Assistant

PROJECT OBJECTIVE:
Build a production-level private ChatGPT system for companies where employees can upload internal documents and ask questions. The AI assistant should answer using company data with accurate citations, document references, and role-based access control.

The project must demonstrate:
- Large Language Models (LLM)
- Retrieval Augmented Generation (RAG)
- Vector Databases
- Backend Engineering
- Authentication
- Cloud Deployment
- AI System Design
- Enterprise Security
